# odin-test-practice
The Odin Project JavaScript Test Practice

## Overview

Functions and test cases for:

    - capitalize (takes a string and returns it with the first character capitalized)
    - reverseString (takes a string and returns it reversed)
    - calculator (contains functions for: add, subtract, divide, and multiply)
    - caesarCipher (takes a string and a shift factor and returns it with each character “shifted”)
    - analyzeArray (takes an array of numbers and returns an object with average, min, max, and length of the array)
